# PassFlow Design Studio plugin

In Figma desktop, create a development plugin to obtain your assigned plugin ID. Put that ID into `manifest.json` in place of `REPLACE_WITH_YOUR_FIGMA_PLUGIN_ID`, then use Plugins → Development → Import plugin from manifest. This package does not claim ownership of an existing published plugin.

1. Create an ID card, digital pass or wristband starter frame, or select your existing frame.
2. Select each dynamic layer and map it using the field dropdown. Static artwork needs no mapping.
3. Select the whole frame. Enter physical dimensions matching its aspect ratio.
4. Validate and export. Import the downloaded JSON inside the event's Design studio.
5. Preview with a long sample name, review QR/safe-area validation, save a draft, and publish when ready.

The original frame is never modified during export. A temporary clone preserves layout while removing dynamic placeholders from its background image. Static visuals are rasterized; dynamic text uses Arial. Mixed fonts and rotated dynamic nodes are rejected explicitly. PNG backgrounds are limited to 450 KB and bundles to 750 KB. QR credentials are generated by PassFlow and are never baked into the template.

This plugin uses a local JSON transfer, not OAuth or direct event synchronization. It does not read attendee data or require secrets. The existing plugin source was not present in the repository; this package is independently installable and has not yet been verified inside a live Figma desktop session.
