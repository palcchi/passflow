# PassFlow: daftar perubahan 28 September 2026

Status: implementasi source lokal pada `feat/event-management-design-system`, belum live. Main `0d666c6` sudah digabung, termasuk navigasi dan avatar terbaru. Tidak ada push, deployment, migrasi production, publikasi plugin, atau perubahan DNS. “Oke/lanjut/good response” bukan izin release.

## Pengelolaan data dan UI

- Edit, search/filter/pagination, aktivasi/nonaktif, dan penghapusan gate/station, zone, activity, benefit.
- Penghapusan data dengan referensi/riwayat ditolak; organizer dapat menonaktifkannya. Attendee dengan scan/activity/benefit history juga dilindungi.
- Validasi permission dan referensi lintas-event. Penonaktifan zone/activity ikut menonaktifkan station terkait.
- Feedback error/sukses pada mutation, termasuk tema dan konfigurasi QR.
- UI scanner dipertahankan; migration guard memperkuat lifecycle resource.
- Navigasi/avatar terbaru dipertahankan. Reset layout akibat pathname key dan rewriting teks global dihapus pada checkpoint sebelumnya. State bubble navigasi dirapikan tanpa effect reset.

## Customize dan pass

- Appearance menjadi **Quick Setup** untuk identitas, warna, artwork, dan default pass.
- Design menjadi pusat koneksi Figma, draft, preview, publish, dan alamat event.
- Website tidak lagi ditawarkan dalam pemilih format editor internal; penyimpanan website melalui editor internal ditolak.
- Tool pass tetap tersedia untuk digital, ID card, wristband: layer teks/gambar/shape/QR, dynamic field, ukuran mm, posisi, lock/hide, undo/redo, sample attendee, safe-area guide.
- Shared model/renderer untuk preview, hasil publik, dan cetak. Desain per-ticket-category dan fallback default; cetak memakai credential valid.
- Validasi QR: jumlah, ukuran minimum, persegi, batas area, overlap.
- Draft/published/archived, optimistic revision, immutable published version, salin versi ke draft baru, unpublish.

## Plugin Figma standar

- Source baru `figma-plugin-standard/`, terpisah dari account-library plugin lama.
- Pairing kode acak sekali pakai, berlaku 10 menit; lima kode/event/10 menit dan pembatasan percobaan penukaran.
- Credential event-scoped 30 hari di device clientStorage. Database menyimpan hash; tidak ada service-role key dalam plugin atau metadata dokumen.
- Koneksi bisa dicabut dan permission pembuat diperiksa ulang setiap sync.
- Simple/Advanced Mode, starter Desktop + Mobile, serta Hero, About, Tickets, Schedule, Speakers, Sponsors, Venue, FAQ, CTA, Footer.
- Insert block, assign responsive frame, assign Register/Tickets/Schedule/My Pass/Custom Link dan data dasar event.
- Identitas/binding menggunakan metadata, bukan nama layer. Rename aman.
- Event diingat; buka ulang plugin/ganti page memerlukan konfirmasi event agar salinan file tidak diam-diam memperbarui event lama.
- Auto-sync debounce 1,5 detik, status, retry, penanganan revision conflict, dan tautan preview.
- Sync hanya ke draft. Publish hanya dari PassFlow. Panel web refresh saat terlihat agar draft baru muncul.
- Build script membuat ZIP development plugin lokal. Manifest masih memerlukan ID resmi Figma.

## Website hasil Figma

- Structured HTML untuk teks, layout dasar, tombol, data event, dan tiket, bukan satu PNG website.
- Artwork tertentu diekspor per-layer. Desktop/Mobile terpisah; fallback konten sederhana jika Mobile belum dibuat.
- Preview memakai renderer publik yang sama; action dinonaktifkan dalam preview.
- Publish memvalidasi action registrasi, batas frame, target anchor dan revision yang direview.
- Custom link dibatasi HTTPS/anchor valid; payload, gambar, jumlah node dan dimensi dibatasi.
- Registration/My Pass menuju flow claim yang sudah ada. Legacy OAuth/copy-link dipisah ke halaman Legacy.

## Subdomain dan webhook

- Mapping event/subdomain, unique constraint, validasi label/reserved names, dan permission organizer.
- UI cek availability/simpan alamat; database menangani race reservasi.
- Satu aplikasi melayani `eventname.passflow.my.id`. Hanya event published bisa di-resolve; hostname tidak valid/nested ditolak. Tenant tidak memakai forwarded-host.
- Auth/admin tetap pada domain utama. Flag wildcard default nonaktif.
- Receiver webhook memverifikasi subscription, passcode, file key, timestamp. Hanya menandai kemungkinan perubahan eksternal; tidak sync/publish konten.

## Belum live / batas implementasi

1. Empat migration baru belum diterapkan ke database sebenarnya. PGlite fixture bukan pengujian E2E production.
2. Service-role server perlu dikonfigurasi. Plugin memerlukan registered ID, uji Figma nyata dan distribusi resmi. Development install membutuhkan Figma desktop, bukan flow iPad-only.
3. OAuth lama belum terbukti pulih. Pairing baru tidak membutuhkan OAuth organizer, tetapi endpoint baru belum dirilis.
4. Wildcard DNS, domain attachment, TLS dan canonical auth perlu diverifikasi sebelum mengaktifkan flag. Reservasi alamat tidak membuat domain langsung live.
5. Webhook provisioning dan verified file-key mapping belum aktif. `figma.fileKey` tidak tersedia pada semua distribusi; webhook tidak wajib untuk auto-sync saat plugin terbuka.
6. Renderer belum menerjemahkan semua fitur Figma: font di luar whitelist, mixed styles, efek, opacity, rotasi, masks dan layout kompleks disederhanakan. Schedule/Speakers/Sponsors/FAQ masih konten visual statis, bukan CMS dinamis baru.
7. Perlu uji nyata login → pairing → edit → preview → publish → claim → scan dan cetak fisik setelah release diizinkan.

Custom domain organizer/tier Pro tetap tahap lanjutan. Kontrak produk: `figma-product-contract.md`.
